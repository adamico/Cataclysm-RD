# Cataclysm: Rusted Dawn

A port of the Cataclysm engine to Rust, with faster simulation in dense areas (labs above all) as a side goal. It starts from a frozen upstream release, the **Baseline**: either Cataclysm: Bright Nights v0.13.0 or Cataclysm: Dark Days Ahead 0.H-RELEASE, still to be chosen.

Status: Phase 0 (estimate and go/no-go). There is no code yet. The planning lives in the `wayfinder:map` issue, the [glossary](GLOSSARY.md) and [docs/research/](docs/research/).
